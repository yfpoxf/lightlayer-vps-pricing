## 几个测评没写、但会影响使用的细节

**台湾机型的 IP 是非原生的。** 配置页明确标注 “1 (Non-Native IP)”。非原生 IP 意味着这个地址段不属于该机房本地运营商，部分对 IP 归属地敏感的服务，比如某些地区的流媒体、支付风控、邮箱送达率，可能会受影响。做站群、发信、需要干净 IP 的业务，下单前先想清楚这一点。新加坡和圣何塞的云服务器页面标注的是 1 个 IPv4，没有加“非原生”的说明。

**带宽单位是 Mbps，不是 Gbps。** 香港独服 10Mbps 优化、新加坡云 10Mbps 优化、洛杉矶独服 50Mbps 优化，这几个数字放在 2026 年的语境里不算宽裕。圣何塞那台标的是 1Gbps，是这一批里端口最大的。如果你的用途是持续大流量传输、视频中转、大文件分发，10Mbps 和 50Mbps 会明显吃紧；如果只是建站、跑 API、做轻量代理，10Mbps 够用。

**库存是硬约束。** 新加坡和圣何塞各 50 台，洛杉矶独服 30 台，香港独服 20 台。每款产品每位客户限购 2 台，下单后 1 小时内未支付订单会被取消，名额回到池子里。想买多台做集群的，2 台上限会卡住你，得用不同账号或者换方案。

**线路是分档的。** 香港独服给了三个档位：10Mbps 优化、15Mbps 全向回国、20Mbps 国际。优化线路对大陆访问更友好，国际线路带宽更大但回国质量一般。选哪个取决于你的用户在哪，不要默认“优化”就是唯一正确答案。

不适合的场景同样要说清楚。

只做一两个月的短期项目，别为了“续费同价”多付；首期折扣更猛的方案更适合你，反正你也不会续费。
